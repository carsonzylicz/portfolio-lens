# Portfolio Lens — public

A static, light-mode view of a personal portfolio.

- Per-position actual return charts
- Shares held and share-of-book charts
- Robinhood and Schwab era returns vs SPY and QQQ
- Replacement scatter: missed vs replaced, percent only
- Best 10 buys and sells by relative size and by percent

**No dollar amounts are included.** The page shows percentages, share counts and
relative sizes only. It contains no account numbers or names.

Sources: Robinhood account data and a Schwab trade export. Not investment advice.
